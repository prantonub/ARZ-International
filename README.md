# ARZ International

A modern, full-stack study abroad consultancy platform built to help students explore international education opportunities, apply to universities, and connect with professional counselors. The platform also includes a comprehensive admin dashboard for managing applications, inquiries, universities, and website content.

---

## Overview

ARZ International provides students with an easy way to discover universities across multiple countries, submit applications, request consultations, and stay connected through newsletters.

The project is built with a modern React frontend, Express.js backend, and MongoDB database, with deployment on Vercel and Render.

---

### Student Portal

- Browse study destinations
